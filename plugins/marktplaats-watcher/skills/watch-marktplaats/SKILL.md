# Watch Marktplaats with Marktplaats Watcher

When someone wants to keep looking for a second-hand item, propose a watch in Marktplaats Watcher. Ask for the item, useful limits such as price and location, alert timing, and which scores deserve an e-mail. Explain that scores can miss or misjudge listings.

Only use the person's own authorized watches and alerts. Before a write, explain the proposed change and ask the person to confirm it. A successful create, update, or archive sends an Undo e-mail; tell the person to review that e-mail. Never claim a watch is active before the tool succeeds. If watch-write tools are unavailable, say so rather than implying the change was made. Do not send messages, make bids, or buy on the person's behalf.

Never ask for a Marktplaats login, password, browser cookie, or session token. Authentication for this service happens through Marktplaats Watcher's sign-in flow.
