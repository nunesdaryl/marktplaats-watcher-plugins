# Marktplaats Watcher agent plugins

These plugins help Claude Code and Codex use Marktplaats Watcher's remote MCP server.

Claude Code: `claude plugin marketplace add nunesdaryl/marktplaats-watcher-plugins`, then install `marktplaats-watcher@marktplaats-watcher`.
Codex: `codex plugin marketplace add nunesdaryl/marktplaats-watcher-plugins`, then install Marktplaats Watcher from that marketplace.

MCP URL: https://marktplaatswatcher.app/api/mcp
Setup guide: [agents page](https://marktplaatswatcher.app/agents/)

Account sign-in needs Marktplaats Watcher's OAuth, see the agents page.
